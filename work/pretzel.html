Overview

Snack was a fast-moving startup where new screens were designed by hand. I built Pretzel, a Figma design system based on Apple's Human Interface Guidelines. Design & engineering now had one shared source of truth, which cut design debt and build time.

CompanySnack: Video-first dating for Gen Z
Stage$3.5M-funded startup
My roleProduct Designer, system owner
PlatformiOS 13+ (iPhone SE and up)
ToolsFigma components, variants, auto-layout, team libraries
ShippedPretzel 1.0
01The problem

Fast shipping, slow drift.

Startups ship fast. Speed is better than polish, until it isn't. We had different workstreams (e.g. onboarding, messaging, the video feed) that had different buttons and spacing. Engineers had no source of truth.

/01

No single source of truth

Without design tokens, instances can end up shipped as unintended values.

/02

Rebuilding, not reusing

Without shared components, every handoff meant more one-off UI for engineering to build and maintain.

/03

Growth? Yikes.

Accessibility, Dynamic Type and a future Android app would multiply every inconsistency already in the product.

02The approach

Atoms first, screens last.

I drew from Brad Frost's Atomic design principles, so each page is made out of smaller, constituent parts.

Atoms

Colour, text and effect styles, plus icons.

Molecules

♥  Like

Buttons, badges, toggles and inputs.

Organisms

Send

Messages, navigation bars, cards.

Templates

Screen layouts w/ 4pt grid & 16pt margins.

Pages

Real Snack screens, built from instances.

03Foundations

The dough of the system.

Everything here is interactive. These are Pretzel's actual tokens and rules, rebuilt for the web.

3.1Colour

A "hand-picked" palette named in the colour-### scheme. The names don't encode a use case, which keeps the options open while keeping the number of colours small. Click a swatch to copy its hex.

Transparency comes in 10% steps. Only.

To stop "22% black" turning up in one file and "25%" in the next, Pretzel only allows opacity in 10% increments. Drag the slider: it snaps to the nearest step.

07Reflection

What I'd knead differently.

01Start with tokens in code

Pretzel lived in Figma. Next time I'd export colours, type and spacing as design tokens so Figma and the codebase can't drift apart.

02Put governance in place early

The review process was marked "Future." At startup speed, a lightweight contribution process should come with v1.

03Measure adoption

I'd track how many components are detached and how many instances each one has, so the system's value can be shown with numbers.

04Create a culture around the design system

Involving others in thoughtful co-creation, and using more food-based naming (Pretzel, "chef's kiss") to make the system friendlier. Culture is part of adoption.
